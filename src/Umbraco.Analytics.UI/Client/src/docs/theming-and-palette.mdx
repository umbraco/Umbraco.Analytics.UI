# Theming and palette

The components use Umbraco UI (UUI) tokens only, so they follow the backoffice theme: light, dark and high contrast. Switch the theme in the toolbar above to check any page here.

Colours come from `--uaui-*` custom properties that are worked out from the UUI tokens. See [Foundation > Theme](?path=/story/foundation-theme--swatches) for every colour, in each theme.

## Using the palette in your own elements

To colour your own cell, legend or chart key the same way, add `UauiPaletteStyles` to the element's styles and read the resolved name:

```ts
import { css, html, LitElement } from "@umbraco-cms/backoffice/external/lit";
import { UauiPaletteStyles } from "@umbraco/analytics-ui";

class MyLegend extends LitElement {
  render() {
    return html`<span class="dot"></span>`;
  }

  static styles = [
    UauiPaletteStyles,
    css`
      .dot {
        background-color: var(--uaui-color-series-1);
      }
    `,
  ];
}
```

The colour is the one our share bars use, in the light, dark and high contrast themes.

## Names to read, and names to override

| Read this | For | Override it with |
|---|---|---|
| `--uaui-color-series-1` to `--uaui-color-series-8` | lines and bars (5 to 8 for charts with many series) | `--uaui-series-1` to `--uaui-series-8` |
| `--uaui-color-fill-1` to `--uaui-color-fill-8` | area fills (use at low opacity) | `--uaui-series-N` |
| `--uaui-color-bar-1` to `--uaui-color-bar-8` | livelier bars (5 to 8 are their line colours) | `--uaui-bar-N`, then `--uaui-series-N` |
| `--uaui-color-series-default`, `-positive`, `-warning`, `-danger` | lines of a series coloured by a status (`color: "danger"`) | `--uaui-series-default` and so on |
| `--uaui-color-fill-default`, `-positive`, `-warning`, `-danger` | area fills of a status series (use at low opacity) | `--uaui-series-<status>` |
| `--uaui-color-bar-default`, `-positive`, `-warning`, `-danger` | bars of a status series | `--uaui-bar-<status>`, then `--uaui-series-<status>` |
| `--uaui-color-compare` | the compare period | `--uaui-compare` |
| `--uaui-color-compare-bar` | the compare bar (45% of compare) | `--uaui-compare` |
| `--uaui-color-marker`, `--uaui-color-marker-hover` | chart markers | `--uaui-marker` |
| `--uaui-color-gap-positive`, `--uaui-color-gap-negative` | shading between a series and its compare line: good where the series is doing better than the compare line, bad where worse (flipped by `lower-is-better`) | `--uaui-gap-positive`, `--uaui-gap-negative` |
| `--uaui-color-tint-positive`, `-negative`, `-neutral`, `-warning` | pill and track backgrounds | `--uaui-tint-*` |
| `--uaui-color-text-positive`, `-negative`, `-neutral`, `-warning` | text on those tints (4.5:1 in every theme) | `--uaui-text-*` |

- `--uaui-color-*` are read-only. Override with `--uaui-*` only. Setting `--uaui-color-*` is unsupported.
- To override, set `--uaui-*` (for example `--uaui-series-1: #0a7`) on an ancestor, so it reaches both your elements and ours. Setting it on your own `:host` only changes your element.
- The block sets `color-scheme` on the element's `:host`. Its subtree inherits it, slotted children included, which aligns native controls and scrollbars with the UUI theme. With no UUI theme it resets to `normal`.
- The palette is tested to 3:1 for lines and bars in all three themes. If you override a colour, you own its contrast.

## Many series

Slots 1 to 4 are the main colours. Slots 5 to 8 (teal, orchid, coral and olive) are for charts with many series, such as
one per source page: a series past the fourth takes them before the colours repeat from slot 1. They are mixes of UUI
palette shades, picked to stay apart from slots 1 to 4, the status colours and the compare colour.

- Pass the series largest first. Above 8 series the legend shows the first 7 and a "Show N more" button, and the
  tooltip lists the 7 largest (in series order) and "+N more". The hidden table always has every series.
- Past 8 series two series share a colour. To keep colours unique, group the smallest into one "Other" series with
  `color: "default"` (a neutral grey).
- In your own Chart.js chart, `uauiChartColors(host).series` now has all 8 slots (it had 4). Code that cycles with
  `series[i % series.length]` gives series 5 and up the new colours; `series[i % 4]` keeps the four main ones.

## Colour a series by its meaning

A chart series' `color` takes a palette slot (`1` to `4`) or a status colour: `"default"`, `"positive"`, `"warning"` or `"danger"`, the same names (`UauiStatusColor`) as the status cell and `uui-tag`. Use a status when the colour means something, such as failed workflows in `"danger"`:

```ts
chart.series = [
  { id: "approved", label: "Approved", color: "positive", points },
  { id: "pending", label: "Pending", color: "warning", points },
  { id: "errored", label: "Errored", color: "danger", points },
  { id: "cancelled", label: "Cancelled", color: "default", points },
];
```

- It works in every kind (line, area, bar, stacked bar), and in the legend and tooltip. A compare line or bar keeps the compare colour.
- `"default"` is a neutral grey, as in the status cell. `"warning"` looks like slot 3 and `"danger"` like slot 2 in every theme, so don't mix those slots with those statuses in one chart: the chart warns once in the console if you do. `"positive"` and `"default"` differ from every slot: slot 4 is lavender in the dark theme, not a green, so it doesn't read as positive.
- Any other value draws the series in the slot of its position.
- Say the meaning in the label too. The colour only repeats it.
- For your own Chart.js chart, `uauiChartColors(host).status.danger` gives the same `{ line, fill, bar }`.

## Everything else is a UUI token

The components set no colours of their own besides these. Spacing, borders, text and surfaces come from `--uui-*` tokens, so a theme that changes them changes the components too. Don't hard-code a colour next to a component: use a UUI token or a `--uaui-color-*` name.
