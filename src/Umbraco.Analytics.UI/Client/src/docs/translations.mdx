# Translations

All text comes from localization keys. No element has fixed text.

- English ships with the package as a `localization` extension at weight 200.
- Keys start with `uauiAnalytics_`, such as `uauiAnalytics_errorHeadline`.
- Generic words reuse Umbraco's own keys: Retry is `general_retry`, Search is `general_search`, Loading is `general_loading`.
- Numbers and dates use the backoffice user's culture, not a key.

## Change a string or add a culture

Register your own `localization` extension with the keys you want to change. Yours wins at the default weight of 100.

```json
{
  "type": "localization",
  "alias": "MyProduct.Uaui.Localization.Da",
  "name": "My product analytics (da)",
  "js": "/App_Plugins/MyProduct/uaui-da.js",
  "meta": { "culture": "da" }
}
```

```ts
export default {
  uauiAnalytics: {
    errorHeadline: "Noget gik galt",
    errorDescription: "Dataen kunne ikke hentes.",
  },
};
```

The section name is the key prefix: `errorHeadline` above is `uauiAnalytics_errorHeadline`. Placeholders are `{0}`, `{1}` and so on. Keep them in your text.

Some of the keys:

| Key | English |
|---|---|
| `uauiAnalytics_emptyHeadline` | No data yet |
| `uauiAnalytics_emptyDescription` | Try a wider date range. |
| `uauiAnalytics_errorHeadline` | Something went wrong |
| `uauiAnalytics_errorDescription` | The data could not be loaded. |
| `uauiAnalytics_kpiNoData` | No data for this period |
| `uauiAnalytics_groupByDay`, `Week`, `Month` | Day, Week, Month |
| `uauiAnalytics_pagerPageSize` | Per page |

The full list is the `uauiAnalytics` section of `src/lang/en.ts` in the repo.

## For contributors: fixed text goes through keys

Every user-facing string goes through a key: visible text, `aria-*`, `title`, `placeholder`, visually hidden text, and announced joins and separators. Reuse an Umbraco key for a generic word (`general_*`, `buttons_*`). Otherwise add a `uauiAnalytics_*` key to `en.ts`.

- Keys are whole literals, never built from parts, so they can be found and checked.
- Don't join translated words in code. Make one key with placeholders, like `uauiAnalytics_dateRangeRange` ("{0} to {1}"), so another language can reorder them.
- The localization tests fail on text that isn't a key, and on keys that are missing or unused.
